\# What Did I Learn?



\## 1. Technical Knowledge

* I learned how to create Django models and store information in a database.

\## 2. Project Development

* I learned how to develop a real-world web application using Python and Django.
* I understood how to manage product details, dimensions, weight, shipping boxes, and customer orders.
* I learned how to implement a box recommendation system based on product dimensions and weight.
* I understood how to check whether products fit inside a shipping box by considering different product orientations.
* I learned how to calculate shipping costs, potential savings, and box utilization.
* I gained experience creating a 3D visualization to display how products are arranged inside a shipping box.
* I also learned how to organize project files, debug errors, and manage my code using Git and GitHub.



\## 3. Challenges Faced

* Understanding the packing logic: Initially, understanding how to fit multiple products inside a shipping box was challenging. I worked on the packing algorithm to check product dimensions and different orientations.
* Product dimensions: Checking whether products could fit inside a box was another challenge. I used Python functions to compare product dimensions with available box space.
* Box recommendation: Selecting the most suitable and cost-effective box was challenging. I implemented logic to check box capacity, maximum weight, and cost.
* 3D visualization: Displaying products inside the selected box was challenging. I used Three.js to create a 3D representation of the product arrangement.
* Testing and debugging: I faced some difficulties while checking the application. I solved them by running test cases, checking errors, and correcting the code.



\## 4. Testing

* I learned how to write automated test cases in Django using Python's testing framework.
* I understood how to test models, functions, views, and the box recommendation logic.
* I learned how to identify errors and verify that the application produces the expected results.
* I tested different situations, such as products fitting inside a box, products exceeding box capacity, product quantities, and orders without suitable boxes.
